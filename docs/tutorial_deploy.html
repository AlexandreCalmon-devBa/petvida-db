🚀 Hospedagem Gratuita Total

Aprenda, do absoluto zero, a colocar sua API (Vercel) e Banco de Dados MySQL (Aiven) online para o mundo inteiro acessar!

💡 Entenda o conceito: O Vercel hospeda "sites e códigos" (como nosso Node.js), mas não guarda dados de forma permanente. O Aiven é um servidor dedicado a guardar tabelas de banco de dados. Juntando os dois, temos uma aplicação completa!
Passo 1 Preparando seu código (Vercel.json)
▼

Antes de criarmos contas, precisamos dizer ao Vercel como ler nosso código. Isso é feito com um arquivo na raiz do projeto.

  1. Crie um arquivo na pasta principal do seu projeto com o nome exato de vercel.json.
  2. Clique no botão "Copiar" abaixo e cole dentro desse arquivo:
    3. {
  "version": 2,
  "builds": [
    { "src": "src/server.js", "use": "@vercel/node" }
  ],
  "routes": [
    { "src": "/(.*)", "dest": "/src/server.js" }
  ]
}
  3. Abra o arquivo onde você faz a conexão com o banco de dados (ex: src/config/database.js) e garanta que você ativou o SSL se estiver no Vercel (o Aiven bloqueia quem tenta conectar sem SSL).
  4. Faça o commit e o Push dessas mudanças para o seu GitHub! O código precisa estar lá.
Passo 2 Criando o MySQL na Nuvem (Aiven)
▼

O Aiven é fantástico porque ele te dá um MySQL real sem pedir cartão de crédito.

  1. Acesse Aiven.io e clique em Start for Free.
  2. Faça login usando o Sign in with GitHub ou Google (é mais rápido e você não precisa validar e-mail).
  3. Logo na primeira tela do painel, clique no botão azul Create Service.
    4. ⚠️ CUIDADO AQUI: Haverá dezenas de logotipos. NÃO clique no primeiro (Kafka). Role a página para baixo e clique especificamente no ícone do golfinho, o MySQL.
  4. Desça até a seção Service Plan. Escolha a aba Free ou Hobbyist (0$).
  5. Na seção Cloud Region, escolha a bandeira do Brasil (São Paulo - AWS) para a sua API ficar mais rápida!
  6. Clique no botão azul no final da página Create Service.
  7. Agora você verá uma tela de "Building". Vá tomar uma água 🚰. Demora cerca de 2 a 3 minutos para a luzinha ficar verde.
Passo 3 Pescando suas Credenciais
▼

Com a luzinha verde acesa, você precisa pegar a "chave de casa" para conectar no banco.

  1. Na aba Overview do seu novo MySQL, encontre a caixa chamada Connection Information.
  2. Você vai ver 4 informações vitais. Deixe essa aba aberta e não feche:
    • Host: Uma URL gigante terminada em aivencloud.com
    • Port: Geralmente uma porta estranha (não é a 3306), ex: 14100
    • User: avnadmin
    • Password: Clique no ícone de "olhinho" 👁️ para poder copiar a senha.
[Guarde essas 4 informações para o Passo 5]
Passo 4 Injetando as Tabelas (Opcional, mas necessário)
▼

Seu banco novo na nuvem está vazio! Você precisa rodar os scripts SQL nele.

  1. Abra o DBeaver (ou MySQL Workbench) no seu PC.
  2. Crie uma Nova Conexão MySQL.
  3. Cole o Host, Port, User e Password do Aiven que pegamos no passo anterior.
  4. MUITO IMPORTANTE: Na aba de SSL do DBeaver, marque a opção para "Exigir SSL" (Require SSL). Sem isso, dá erro!
  5. Clique em Test Connection. Se deu verde, parabéns!
  6. Abra seus scripts (schema, seed, etc), cole no DBeaver e execute. Agora seu banco na nuvem tem tabelas!
Passo 5 Vercel: Colocando a API no Ar
▼

Hora de fazer a API nascer na internet!

  1. Acesse Vercel.com.
  2. Clique em Sign up e escolha Continue with GitHub. Autorize o aplicativo.
  3. Você vai cair no painel. Clique no botão preto Add New... e escolha Project.
  4. O Vercel vai listar seus projetos do GitHub. Encontre o seu projeto e clique no botão Import.
  5. Você verá a tela "Configure Project". Role a página até encontrar o menu sanfona chamado Environment Variables (Variáveis de Ambiente). Clique nele para abrir.
    6. Aqui você vai conectar o Vercel ao Aiven! Adicione uma por uma clicando em Add: 
    Name: DB_HOST
Value: (Cole aqui o Host do Aiven)

Name: DB_PORT
Value: (Cole aqui a Port do Aiven)

Name: DB_USER
Value: avnadmin

Name: DB_PASSWORD
Value: (Cole a senha do Aiven)

Name: DB_NAME
Value: defaultdb
  6. Adicionou as 5 variáveis? Perfeito! Agora clique no botão gigante Deploy.
  7. A tela vai ficar preta com vários textos rodando. Isso é o Vercel construindo sua aplicação.
  8. Em menos de 1 minuto vai chover confete na sua tela! 🎉
Fim O que fazer agora?
▼

O Vercel te deu um link lindo (ex: seu-projeto.vercel.app).

Basta clicar nesse link, colocar /api-docs no final da URL lá em cima no navegador, e mandar para todos os seus amigos verem o seu Swagger puxando os dados reais do banco direto da nuvem!
