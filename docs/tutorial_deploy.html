🚀 Deploy Master: Node.js + MySQL na Nuvem

Aprenda a colocar sua API no Vercel e seu banco de dados no Aiven de forma 100% gratuita.

💡 Por que separar? O Vercel é excelente para rodar código (Node.js/React), mas não hospeda bancos de dados relacionais como o MySQL. Por isso, usamos o Aiven para o banco e o Vercel para a API.

Passo 1 Preparando a API (Node.js)

Antes de subir, seu projeto precisa estar pronto para o Vercel.

  1. Na raiz do seu projeto, crie um arquivo chamado vercel.json: 
    {
  "version": 2,
  "builds": [
    { "src": "src/server.js", "use": "@vercel/node" }
  ],
  "routes": [
    { "src": "/(.*)", "dest": "/src/server.js" }
  ]
}
  2. No seu arquivo principal (ex: server.js), não execute o app.listen() no ambiente do Vercel. Envolva-o em um IF e sempre exporte o app no final: 
    if (process.env.NODE_ENV !== 'production' && !process.env.VERCEL) {
  app.listen(3000, () => console.log('Servidor local rodando!'));
}
module.exports = app;
  3. No seu arquivo de conexão com o banco (ex: database.js), certifique-se de forçar o SSL para conexões remotas: 
    const pool = mysql.createPool({
  host: process.env.DB_HOST,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
  ssl: process.env.VERCEL ? { rejectUnauthorized: false } : undefined
});

Passo 2 Criando o MySQL Grátis no Aiven

O Aiven oferece um banco MySQL gratuito e super rápido.

  1. Acesse Aiven.io e crie uma conta gratuita.
  2. No painel (Console), clique no botão azul Create Service.
  3. Selecione MySQL como serviço.
  4. Na seção Service Plan, desça até o final e escolha a opção Free / Hobbyist.
  5. Selecione uma região próxima (ex: AWS South America / São Paulo) e clique em Create.
  6. Aguarde cerca de 2 minutos até o status ficar ✔ Running.
  7. Na aba Overview, procure a seção Connection Information. Guarde bem o Host, Port, User e Password (clique no olho para ver a senha).

Passo 3 Subindo as Tabelas pro Banco

Você precisa conectar sua máquina local no Aiven para rodar o CREATE TABLE e os INSERTs.

  1. Você pode usar ferramentas visuais como o DBeaver ou MySQL Workbench.
  2. Crie uma nova conexão e cole o Host, Usuário e Senha que pegou no Aiven.
  3. Atenção: Nas configurações da ferramenta, exija SSL (Required) para a conexão.
  4. Conectado, abra os seus scripts SQL (ex: schema.sql) e mande executar tudo de uma vez.

Passo 4 Deploy da API no Vercel

Com o código no GitHub e o banco online, é hora de juntar os dois.

  1. Faça o push de todo o seu código para o GitHub.
  2. Acesse Vercel.com e faça login com seu GitHub.
  3. Clique em Add New... -> Project.
  4. Encontre seu repositório na lista e clique em Import.
  5. Na tela "Configure Project", abra a aba oculta chamada Environment Variables (Variáveis de Ambiente).
  6. Adicione os dados do seu banco do Aiven um a um:
    • DB_HOST = (ex: mysql-xyz-suaorg.aivencloud.com)
    • DB_PORT = (geralmente porta diferente da 3306)
    • DB_USER = avnadmin
    • DB_PASSWORD = (Sua senha secreta)
    • DB_NAME = defaultdb (ou petvida, se tiver criado)
  7. Clique no botão azul Deploy.
🎉 Tudo pronto! Em menos de um minuto o Vercel vai gerar uma URL pública e sua API estará conectada na nuvem conversando com o Aiven de forma segura!
